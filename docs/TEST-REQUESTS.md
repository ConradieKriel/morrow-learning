# Morrow Option 2 test requests

Use these realistic prompts to check whether Gemini creates different kinds of activities rather than defaulting to multiple-choice quizzes. Run each prompt in live Gemini mode and record whether the preview works on desktop and a phone.

1. **Grade 6 Mathematics:** Make a fraction wall where learners can drag fraction tiles to compare halves, thirds, quarters and sixths. Show when two fractions are equivalent.
2. **Grade 7 Natural Sciences:** Build a water-cycle simulation where learners change the temperature and see the evaporation rate change.
3. **Grade 5 English:** Make a story where learners choose what the main character does next. Give feedback after each choice and show a short ending.
4. **Grade 8 Natural Sciences:** Create an interactive food-chain diagram. Learners should remove one organism and see how the rest of the chain is affected.
5. **Grade 4 Mathematics:** Make a place-value game using number cards. Learners build the largest possible four-digit number and get a hint when they make a mistake.
6. **Grade 9 Geography:** Create a labelled interactive diagram of a river's upper, middle and lower course. Learners tap each section to reveal features.
7. **Grade 7 History:** Make a timeline activity where learners place six events in chronological order. Shuffle the event cards each time.
8. **Grade 6 Life Skills:** Build a decision activity about healthy habits. Learners make choices and get simple explanations of the consequences.
9. **Grade 8 Mathematics:** Make a coordinate-plane explorer. Learners move a point and see its x and y coordinates update.
10. **Grade 7 English:** Create a word sorting activity where learners group nouns, verbs and adjectives by dragging each word into the right column.

For every prompt, check that the complete activity appears in the preview, that its interactions work, and that it remains usable at a narrow phone width. If an activity reports an error, confirm that the teacher preview tries no more than two fixes and then returns to the last working version.
